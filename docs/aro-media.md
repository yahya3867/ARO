# ARO media

Refreshed November 18, 2026 from the running ARO application. These are browser captures of a separate, seeded demo session. Existing demo sessions were not reset.

## Published demo

The landing page plays [the ARO submission video](https://www.youtube.com/watch?v=gyXCHbkH4Xs) in a YouTube privacy-enhanced embed. The hover preview uses its YouTube thumbnail and verified duration of 2 minutes 15 seconds.

## Archived capture assets

- `public/landing/aro-demo.mp4`: 80.13-second, 1280 × 720 H.264 walkthrough. Shows the medicine investigation and handoffs, calculated stock depletion, transfer approval, execution, operational report, replenishment authorization, simulated supplier delivery, Board, audit trail, and event picker. The edit joins actual browser-capture sequences and has no narration. The workflow uses ARO's deterministic demo tools and persistent demo records.
- `public/landing/aro-poster.png`: the medicine transfer approval screen from the same recording session.

These earlier capture files are retained as source assets; the landing page now uses the published YouTube demo above.
